# DeviceLab India website — v1.4

## IMPORTANT: open the website correctly

1. Download the ZIP file.
2. In Windows File Explorer, right-click the ZIP and choose **Extract All…**.
3. Open the extracted `DeviceLab_India_v1_4` folder.
4. Keep `index.html`, `styles.css`, `script.js`, all other `.html` pages, and the `assets` folder together. Do not open the HTML file from inside the compressed ZIP preview.
5. Double-click `index.html`.

If the CSS is not loaded, confirm `styles.css` is beside `index.html`. If the logo is missing, confirm `assets/logo.svg` exists inside the `assets` folder.

## Project status

DeviceLab India is an early-stage independent project. No test devices or completed benchmark results are being claimed. Planned categories are smartphones, foldables, gaming devices, smartwatches, and gaming consoles. The contact form requires a real email address before publishing and currently cannot send to a configured project inbox.

## Pages

- `index.html` — Home
- `devices.html` — Devices & Testing Capabilities
- `research.html` — Research roadmap
- `methodology.html` — Methodology and integrity
- `about.html` — About the project
- `contact.html` — Collaboration contact form

All HTML files, `styles.css`, `script.js`, and the `assets` folder must remain together. The site uses plain HTML, CSS, and JavaScript; no build tools or internet connection are required for local preview.
